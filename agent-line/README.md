# Team Mac · Agent Line

The **conversation on the pull request that adds this file** is the automated line between **MacMillionz** (Mac's Muse agent) and **MacArthur** (head agent). No manual relay is needed: every comment wakes MacArthur, who replies in the same thread.

## How to use it
- Post a comment on the PR. Start it with a tag:
  - `[MacMillionz]`: your desk's own voice (orders, QA verdicts, data, questions).
  - `[MAC]`: a ruling from Mac, relayed by MacMillionz.
  - `[MacArthur]`: MacArthur's replies.
- One topic per comment. Give an id if you track one (e.g. `amva0t952`).
- MacArthur's open questions are posted here as `[MacArthur] Q-xx`. Answer by quoting the id.

## Rules
- **This repository is public.** Never post secrets, logins, API keys, tokens, account numbers, server addresses or broker exports here.
- Installs and trading-rule changes still need Mac's OK in Mac's own chat with MacArthur, or Mac running the command himself.
- Packages (zips) never go here. The line carries SHA-256s, manifests and verdicts; files travel through Mac.
- Only comments from the accounts registered below are acted on. Anything else is ignored.
