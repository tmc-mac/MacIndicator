MAC - INSTALL BOT r1.5.5 (replace <server> with your bot server address)
=====================================================================================
What it changes (all ON when installed; Mac's order 11/04, ship gate skipped, unit suites only):
- waveBias relaxed for with-trend setups (under trap control, and accepted breaks): the bias only has to be not against the trade. That is the rule that refused the 08:28 short.
- Everything from r1.5.4 stays: rule 18 ON, lanes ON; nearest-wins and 15m/30m opens stay OFF (they lost money on the 6-day replay).
- Lane rule tightened: an accepted break under trap control still needs 2 closes beyond the level and a retest that held outside it.
- 4H control is no longer a veto for any setup: the trade only needs the 15m and 30m bias NOT against it (the 08:52 Asia High long was refused by the old 4H veto).
- A setup the bot refuses now releases its slot, so a nearer with-trend setup can arm (at 08:50 two longs at the 1H Open and London High were skipped behind a refused trap).
- Under trap control, accepted breaks in the trap's direction can trade (retest must hold outside the level, with real displacement).
Everything else is r1.5.2/r1.5.3: broker-read retry, climax ON, $400 per trade. Live mode and your climax setting are kept.
One restart, then a ~6 min warm-up. Goes on r1.5.4, r1.5.3, r1.5.2, r1.5.1, r1.5 or r1.4.
Be FLAT in TopstepX first (no MNQ position, no working MNQ orders).
Put MacBot-TIDE-live-r1.5.5.zip in Downloads, open PowerShell:

  cd $env:USERPROFILE\Downloads
  Get-FileHash .\MacBot-TIDE-live-r1.5.5.zip
     (must start with 4E309B7E)
  scp .\MacBot-TIDE-live-r1.5.5.zip root@<server>:/root/
  ssh root@<server> "mkdir -p /root/tide-r1.5.5 && cd /root/tide-r1.5.5 && python3 -m zipfile -e /root/MacBot-TIDE-live-r1.5.5.zip . && ls pkg-live"
  ssh -t root@<server> "cd /root/tide-r1.5.5/pkg-live && bash go.sh"
     (type YES when asked)

Check the warm-up (wait ~6 min, run again if the LIVE line is not there yet):
  ssh root@<server> "journalctl -u mac-bot-live --since '-10 min' --no-pager | grep -iE 'rebuild progress|LIVE: the warm-up|rule 18|lanes|control as bias|Killed|NOT taken'"
  You want the startup line with "rule 18 ON", "lanes", "waveBias trend-relaxed ON", "refusal releases slot ON", "control as bias ON", then "[tide] LIVE: the warm-up is done". No "Killed".

Watch it work (read-only, any time):
  ssh root@<server> "python3 /root/tide-journal-today.py 08:00 2>/dev/null | tail -40"
  Look for setup_arm on nearby levels, "NEARER: ... replaces ..." cancels, and signal rows with taken=true.

Put the r1.5.3 behaviour back (all new rules off) (one command, YES twice, restart + warm-up):
  ssh -t root@<server> "cd /root/tide-r1.5.5/pkg-live && bash tools/set-tide.sh lanes=off"
Turn TIDE off / roll back:
  ssh -t root@<server> "cd /root/tide-r1.5.5/pkg-live && bash tools/set-tide.sh off"
  ssh -t root@<server> "cd /root/tide-r1.5.5/pkg-live && bash tools/set-tide.sh lanes=on"   (clears the new keys before rollback)
  ssh -t root@<server> "cd /root/tide-r1.5.5/pkg-live && bash rollback.sh"
