# Desk C: which entry scenarios lose money (first-order filter study)

Desk C, 11/11. Question: which entry scenarios lose money, so a simple filter or parameter change lifts expectancy?

## Answer in short

**No filter survives.** 103 candidate "skip this bin" filters were tested on the focus cohort; **0 pass Benjamini-Hochberg at q = 0.10**, and no filter's 95% bootstrap interval excludes zero. The smallest raw p is 0.032 against a first-rank BH threshold of 0.001. Nothing here justifies a config change on its own.

Two facts matter more than any single split:

1. **The focus cohort is break-even live, not profitable:** 149 trades, 62% wins, net +$78 (+0.09 pts/contract). TP1 trades made +$7,191 (81), full stops cost -$5,375 (26), no-progress exits cost -$1,737 (42).
2. **The two date halves disagree.** 10/28-10/30 made +$819 (61 trades, 7 full stops); 11/02-11/10 lost -$742 (88 trades, 19 full stops). Most "bad" bins are bad only in the second half, and one day (11/03: 31 trades, 11 full stops, -$1,486) drives most of them.

Also noted, failing the hold-out: control score 0.30-0.45 (n=41, -$1,535, p 0.032; half 1 was +$117, and the "stronger control is worse" direction has no mechanism); Asia shorts (n=35, -$1,354; half 1 +$205, older +1.4 pts/c); sweep depth > 25 pts (n=55, -$1,429; half 1 +$208).

Scenarios that showed **no** loss pattern: re-entries at the same level (2nd entry +$670, re-entry after a win +$216, n=38), the stop cap (capped +$171 vs not capped -$93), target room, clock position against 15m / 1H / 4H boundaries, chased entries by slip. The np1 stretch flag marks *winners* here (n=12, +$426), so `stretchCheck: 'block'` is not supported.

## What a change would need (no survivors, so these are for a shadow log, not a ship)

- **After-full-stop stand-down:** no config key exists. `reentryCooldown` / `reentryCooldownBars: 1` / `reentryCooldownCandleMin: 5` only waits one 5m candle. It needs a new key (for example `sessionFullStopStanddown`) checked in `cooldownBlock()` in live-executor.js. This conflicts with Mac's standing rule "never stop the bot mid-session", so it is his call.
- **NY longs / level-name list:** no key exists; `levelEvents` is all-or-nothing. It needs a new session x direction or level-name allow-list in lib/levelEvent.js.
- **Control band:** `controlGateMin` (0.05-0.45) is a floor only; there is no ceiling key.

## Cohort and method

- **Focus cohort:** source = levels, path = levels-market, event SWEEP-LOSS or SWEEP-RECLAIM, trade day 10/28 to 11/11 (entries 10/27 15:00 PT to 11/10 16:55 PT), **n = 149**. Includes the 20 trades of 11/09-11/10 rebuilt from the agent-line slices with the audit's own `build.py`. Sizes are 3 lots except 16 early trades at 1-2 lots; net $ is as traded.
- **Hold-out:** (a) focus halves by trade day, 10/28-10/30 (n=61) vs 11/02-11/11 (n=88); (b) the 78 levels-source trades before 10/28 (other rule set, 5 lots, no np1), compared in pts/contract. A bin "holds" if its net is negative in both halves, or negative in the focus cohort and in the older cohort (older n >= 8).
- **Filters tested:** every bin with 8 <= n <= 141 across 31 splits (the 10 briefed scenarios plus 3 of my own: sweep depth, np1 stretch flag, trigger timeframe) = 103 tests.
- **Statistics:** d$ = minus the bin's net. CI and p from a trade-level bootstrap (4000 resamples of the 149 trades); p is one-sided P(d$ <= 0). A day-cluster bootstrap (8 trade days) is shown for the top 15.
- **First-order only:** removing a trade can let another in (cooldown, position overlap); none of this is replayed.
- **No look-ahead:** every feature is known at the entry decision (clock, level, plan, board, the previous closed 5m bar, earlier trades' closed results). MFE / MAE and exits are used only to describe outcomes.
- **Data limits:** `stretch_check` rows exist for 87 of 149 trades; the journal carries no 1m trigger bar, so "speed" uses the previous closed 5m bar and the 15-minute displacement. Day context (`dayType`, `h4Trend`) is journalled for only 14 trades and was not tested. Only 3 trades fall in a session-open window (the blackouts already cover them), and no trade has |control| above 0.45.
- Scripts: `combine.py`, `features.py`, `analyze.py`, `pooled.py` in the `c/` folder beside this file; run with `python3 -I`.
