# Levels PRO r3.6 chart approximation — REVIEW ONLY

**Not ready to install.** This package evolves the v2.8 review at `8aef4a1` toward the reported r1.5.5/r3.6 policy. It is chart-derived, not a live bot feed. Inputs for the changed policies are explicit and must be checked against the user's actual bot configuration. `controlFree` and the climax switch use source defaults; their effective runtime settings are not independently established. The earlier 30-minute open-wait union and time blocks remain unchanged and fixed in this candidate. 15m/30m open zones and nearest-wins remain off.

- `LevelsPRO-v2.8-main.pine` is the daily levels indicator; the review correction hides old control text in the SWEPT tooltip when Old model is off, preserving the SWEPT description. Level drawings and heat code otherwise match the delivered v2.8 main.
- `LevelsPRO-TIDE-r155-partial-review.pine` is the separate chart companion. It ports configurable control-as-bias, accepted-break control-free, accepted-break displacement lane, trend wave threshold, climax gate, rule 18 far-trap replacement and refusal/pending acceptance handling. It separates observed opposed control from eligibility that policy may waive. The title and HUD say chart approximation; it does not claim a live trade.
- Rule 18's distance multiplier defaults to the r1.5.5 source default and is adjustable; zero disables it. A remembered acceptance can arm after a known required-gate refusal if the saved period and age still qualify.

**Material limits:** The chart does not calculate grade points. A setup passing required gates can still be rejected for grade points in the bot, and that missed refusal can affect the pending-acceptance lifecycle, later setups, virtual position and displayed targets. Bias is approximate. News, actual broker state, fills, live order/protection state, early close, and some exit/trailing behavior cannot be known from chart bars. Intrabar history, data feed and warm-up can differ. When several chart signals occur in the same minute, they may be collapsed and their order can differ from the graded bot. The chart's virtual trades and plans are references. Do not use the chart as proof of a bot signal, fill or protection.

The earlier compiler-name collision, state-priority bugs and blocked-alert bug are corrected. Trigger alerts are restricted to 1m charts, require the chart-model fit, and label bot eligibility and grade unknown. Existing TradingView alerts retain the script and input snapshot from creation; changing the chart does not update or stop them. When a final version is approved, inspect and deliberately disable, delete or recreate the relevant alerts.

**Code checks:** `python3 checks/check_far.py`, `python3 checks/check_policy.py`, and `python3 checks/check_release.py` run synthetic correctness checks only. They exercise 8 rule-18 threshold cases, 5 rule-18 arm/replacement cases, 3,352 required-gate cases compared with the included exact r3.6 `gradeOf`, 5 pending-acceptance/refusal cases, and a missing-stop case. The Pine code itself runs through the supplied limited interpreter; these checks are not TradingView compilation or a strategy performance study. The main order check reports zero; the companion order check reports a known nested-`int` false positive and cannot catch every duplicate declaration. The companion rebuilds byte-for-byte using `python3 -I source/tools/build-tide.py <output>`.

No merge, installation, broker access or host access was performed.
