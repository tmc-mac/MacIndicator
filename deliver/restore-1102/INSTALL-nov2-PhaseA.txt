Be FLAT in TopstepX first (no MNQ position, no working MNQ orders).
Put MacBot-nov2-PhaseA-v2.zip in Downloads, open PowerShell:

1) Check the file:
  cd $env:USERPROFILE\Downloads
  Get-FileHash .\MacBot-nov2-PhaseA-v2.zip
     (must start with 74636948)

2) Copy it up and unpack:
  scp .\MacBot-nov2-PhaseA-v2.zip root@<server>:/root/
  ssh root@<server> "mkdir -p /root/nov2b && cd /root/nov2b && python3 -m zipfile -e /root/MacBot-nov2-PhaseA-v2.zip . && ls MacBot-nov2-PhaseA"

3) Config: keeps your FIRST TIDE backup (never overwrites it), then puts the Nov 2 config in:
  ssh root@<server> "mkdir -p /root/nov2; [ -e /root/nov2/config-local.TIDE-backup.json ] || cp -p /opt/mac-bot/config-local.json /root/nov2/config-local.TIDE-backup.json; cp /root/nov2b/MacBot-nov2-PhaseA/config-local.tradeday-2026-11-02.json /opt/mac-bot/config-local.json && grep -c tide /root/nov2/config-local.TIDE-backup.json; echo CONFIG-OK"
     The number before CONFIG-OK should be 1 or more (your saved TIDE config still has its tide settings).
     If it prints 0: STOP and send me the output (the backup is not your TIDE config).

4) Install (type YES when asked):
  ssh -t root@<server> "cd /root/nov2b/MacBot-nov2-PhaseA && ANYBASE=1 MACBOT_DIR=/opt/mac-bot bash install-nov2-phaseA.sh tree"
     It prints "Installed executor: xxxxxxxx" (your current TIDE) - note it.
     You want at the end: "session stamp ... (executor 07e8e798" and "DONE".
     It prints a BACKUP folder (".nov2-phaseA-backup-...") - copy that line and keep it.
     If it says STOP before YES: nothing changed. Put your TIDE config back:
       ssh root@<server> "cp -p /root/nov2/config-local.TIDE-backup.json /opt/mac-bot/config-local.json"

5) Check (wait 2 min):
  ssh root@<server> "journalctl -u mac-bot-live --since '-5 min' --no-pager | grep -E 'session stamp|config-local|Entering live loop|FATAL|ERROR' | tail -20"
     You want: "applied: 29 setting(s) overridden", "Entering live loop", executor 07e8e798. No FATAL.

ROLLBACK to your TIDE (flat first; use the BACKUP folder from step 4):
  ssh -t root@<server> "bash <BACKUP-FOLDER>/rollback-nov2-phaseA.sh <BACKUP-FOLDER>"
  ssh root@<server> "cp -p /root/nov2/config-local.TIDE-backup.json /opt/mac-bot/config-local.json && systemctl restart mac-bot-live"
