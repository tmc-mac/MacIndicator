## Rules as implemented (SPEC-TIDE-r1 + r1.1 + r1.2 + r1.3 + r1.4 + r1.5 + r1.6/r1.6a)
- **Control score** = our Levels PRO board bias score (`biasScore`, lib/levelsPro.js:421-429; the bot reads `lvByTf.M15.biasScore` at live-executor.js:2849), evaluated at every 1m close on the **forming** 15m and forming 30m candle (30m = same function on 30m bars). Line = 0.15 (r1.3: controlGateMin set to 0.15).
- **4H control**: SELL forms when price < 4H open and forming 15m or 30m score <= -0.15; kind *trap* if the period high had reached O4+5 before, else *below*; trapHigh = period high at formation. CANCEL when price > O4 with 15m/30m score >= +0.15 (the opposite control may form on the same reading). VOID when price trades above trapHigh. BUY = mirror. New 4H period = start from scratch.
- **Levels**: 4H Open, PDH, PDL, London H/L, Asia H/L, 1H Open from the port's 15m board (sessionAnchor cme: day = 15:00 PT; Asia = 15:00-24:00 PT, London = 00:00-06:30 PT per helpers.js ptInfo). Asia H/L usable only outside the Asia session, London H/L only outside London (r1.1 "once it exists").
- **Acceptance at L** (r1.2): a reading with price below L and forming 15m/30m score <= -0.15 (short). Lost again by a reading above L with score >= +0.15. Must be seen at a reading taken **before** the retest bar's close (the last allowed reading is the 1m close one minute before the 5m close). Reset each 4H period.
- **Retest** (closed 5m): high >= L-6, high <= L+12, close <= L-0.25, while 4H control = SELL at that 5m close. Defense 1 = the retest bar. Several levels on one bar -> one setup labelled with the top rank (4H Open > PDH/PDL > London > Asia > 1H Open).
- **Entry ref** = the 5m close. **No chase**: skip if L - entry > 25. **Stop** (r1.3) = retest wick extreme + 2 (lib/levelEvent.js:33 STOP_BUF = 2), no 8-pt clamp, no 60-pt skip. r1.4 adds the **4H-wick stop** (trap kind: trapHigh/trapLow; else the current 4H candle's high/low before entry) and the **1H-wick stop** (current 1H candle high/low up to entry; if that extreme is the retest bar itself, also the previous 1H candle), each + 2. **Auto** (provisional map) = 4H for 4H Open / PDH / PDL or any trap-kind control, else 1H. **Size** = min(3, floor($375 / (pts x $2))) (riskRules.sizeForRisk, slip 0); never skipped: 1 MNQ when even 1 > $375 (r1.4 sizing kept in setups.csv only).
- **Money rule r1.5** (money/SPEC-MONEY-r1.md): money stop = 4H wick if <= 75 pts (incl. +2), else 1H wick if <= 75, else **MONEY_NO_FIT** (not traded). Contracts = min(5, floor($150 / (pts x $2))) (Mac ruling: maxContracts 5). W = ceil_tick($200 / ($2 x contracts)). **First touch** on 1m after the entry: +W vs the money stop (same minute = stop), no timed exit, flat at the 14:00 PT close. The flat-only proxy now uses this (exit at +W or the money stop).
- **Stop context C (r1.6, final) + r1.6a**: 4H-type setups (4H Open, PDH, PDL, or any trap-kind control) use the 4H wick, fallback the 1H wick, else MONEY_NO_FIT; hour-type setups (1H Open, Asia, London levels under non-trap control) use the 1H wick only. 1H wick = the current 1H candle's extreme up to the defense close, including the retest/defense bars, no previous-hour fallback.
- **What price did next** (descriptive): max favourable / max adverse points over the next 2 h (1m highs/lows), which side reached 15 / 30 points first.
- **Flat-only column** (proxy, not the bot's exit engine): a signal is *taken* if it fits the money rule and no earlier taken signal is still open (open until +W or the money stop, max-5 sizing). Re-entry needs a retest bar after the exit, and after a stop a new acceptance reading (spec §3).
