# Office

How Team Mac improves the bot day by day. Start with `LOOP.md`.

| File | What it is |
|---|---|
| `LOOP.md` | The process: scoreboard, daily and weekly cycles, evidence ladder, roles, the phone's data contract |
| `LOOPHOLES.md` | The register of everything known to cost money or block the objective |
| `EXPERIMENTS.md` | Each rule under test, with its expectation and kill rule written before the data |
| `tools/` | `loop_daily.py`: journal in, daily card and `office.json` out |
| `state/` | Machine files: `office.json` (read by the phone), `ledger.json`, `experiments.json` |
| `reviews/daily/`, `reviews/weekly/` | The cards |
